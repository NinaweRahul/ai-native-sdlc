# ai-native-sdlc

My practice repo for the Claude Academy [AI-native SDLC playbook](https://academy.claude.com/courses/ai-native-sdlc-playbook).

I'm using a small business snapshot report as the project to work through the course stages: plan, design, build, test, deploy and maintain. It starts with a sales summary for a made-up company, and I plan to add headcount, website traffic, and budget vs actual as I go.

All the data is built into the code, so there's nothing to download. I'll add files to this repo as each lesson needs them.

## Run it

```bash
python sales_report.py
```

It needs Python 3 and nothing else.
